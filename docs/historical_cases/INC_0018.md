- Solution pattern: reduce_batch_size_pause_index_rebuild

## Symptoms
A bulk import of about 10 million records stalled and then failed with memory or lock-wait errors.

## Investigation
Import logs showed one oversized transaction holding locks while indexes were rebuilt after every batch.

## Root Cause
A bulk import stalled because the batch size was too large.

## Resolution
Reduced the import batch size and paused index rebuilding until the load finished.

## Lessons Learned
Load large datasets in bounded batches and defer index rebuilds.
