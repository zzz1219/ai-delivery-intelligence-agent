# Incident Case INC_0064

- Incident ID: INC_0064
- Project: Land Survey Management System (P02), government sector
- Component: Data Import Pipeline (C05)
- Environment: distributed, version v3.2
- Severity: medium
- Reported: 2026-02-21 08:01:00
- Resolved: 2026-02-21 22:07:00 (14.1 hours)
- Root cause: batch_size_too_large
- Solution pattern: reduce_batch_size_pause_index_rebuild

## Symptoms
System response time degraded severely during and after importing 2 million records in a single batch.

## Investigation
Import logs showed one oversized transaction holding locks while indexes were rebuilt after every batch.

## Root Cause
A bulk import stalled because the batch size was too large.

## Resolution
Reduced the import batch size and paused index rebuilding until the load finished.

## Lessons Learned
Load large datasets in bounded batches and defer index rebuilds.
